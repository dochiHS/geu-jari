# 그 자리, 그 계절

청주의 촬영 명소를 **촬영 지점** 단위로 보여주고, 지점마다 사계절 × 빛·날씨(일출·맑음·일몰·비) 조건별 사진을 나란히 비교하는 모바일 웹앱입니다.

## 1주차(중간 점검 1차) 기능

- 지도(OpenStreetMap)에 명소 표시, 위치를 허용하면 내 위치에서 가까운 순으로 정렬 (허용 전에는 청주 시내 기준)
- 명소 정보: 운영시간, 주차, 안전·접근 메모, 오늘의 일출·일몰 시각과 해가 뜨고 지는 방향
- 촬영 지점 격자(사계절 × 일출·맑음·일몰·비). 운영시간 때문에 일출·일몰을 찍을 수 없는 칸은 계산해서 "운영시간 외"로 표시
- 빈 칸을 누르면 사진 올리기 화면으로 이동. 사진 속 촬영 위치·시각을 읽어 어느 명소·어느 칸에 들어갈지 알려줌 (명소 300m 밖 사진은 안내). 사진은 휴대폰 안에서만 읽고 아직 저장하지 않음
- 지금 계절에 따라 표지 계절 표시와 격자의 계절 행 색이 바뀜 (`?season=spring` 처럼 주소 뒤에 붙이면 다른 계절 미리보기)
- 휴대폰 브라우저 메뉴의 "홈 화면에 추가"로 앱처럼 설치 가능

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면 디자인(ChatGPT 작성) + 기능 연결용 이름·스타일 |
| `app.js` | 화면 전환, 지도, 거리 계산, 격자, 해 위치, 사진 분석 |
| `data.js` | 명소 데이터 (1차: 5곳) |
| `manifest.webmanifest`, `icons/` | 홈 화면 추가용 설정과 아이콘 |
| `vendor/` | Leaflet 1.9.4, SunCalc 1.9.0, exifr 7.1.3 |
| `design/chatgpt-original.html` | ChatGPT가 만든 원본 화면 (비교용) |
